# bpsc-cmo v0.5.2 — Add/Remove and two-way question drag-and-drop

## Apply

Apply after v0.5.1. Extract the Paste & Replace ZIP into the existing project root, then run:

```bash
php artisan optimize:clear
```

No migration or dependency updates are required. Updated compiled frontend assets are included. The fixed `readme.md` is unchanged.

## Interaction

- Available questions on the left show an **Add** text button. Clicking it moves the question to Selected Questions on the right.
- Selected questions show the existing **Remove** text button. Clicking it returns the question to the bank on the left.
- Drag a question row or its handle from left to right to add it. Drop over a selected row to insert before/after that row; drop in the panel's free space to append. Empty selected panels also accept drops.
- Drag a selected question back onto the left Question Bank panel to remove it from the selection.
- Drag within the right panel to reorder; Up/Down and numeric ordering remain available as accessible alternatives.
- Drop panels highlight while dragging. Checkboxes, counts and numeric order fields stay synchronized with the actual selection. Active bank searches continue to filter returned questions without affecting the saved selection.
- Click **Save Survey** to persist changes. Questions remain in the bank and other surveys. Removing all active questions still requires the survey to be Draft.
- Without JavaScript, the existing checkbox/numeric-order fallback remains available.
