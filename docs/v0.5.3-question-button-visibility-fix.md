# bpsc-cmo v0.5.3 — Add/Remove visibility fix and update-note organization

## Apply

Apply after v0.5.2. Extract this Paste & Replace ZIP into the existing project root, then run:

```bash
php artisan cmo:organize-update-notes
php artisan optimize:clear
```

No new migration or dependency update is required. Updated compiled frontend assets are included. The fixed root `readme.md` is unchanged.

## Button visibility fix

The previous row toolbar used the `d-flex` utility class, whose `display:flex!important` rule could override the HTML `hidden` attribute. The selection state was updated, but the hidden Remove toolbar could remain visibly rendered in the bank.

The toolbar now uses its own layout class. A scoped `[hidden]` CSS guard enforces hidden controls inside the question picker, and JavaScript sets each Add/Remove/Up/Down button's hidden/disabled state independently.

- Available Question Bank rows show **Add** only; Remove and ordering actions are hidden and disabled.
- Selected Questions rows show **Remove** and applicable ordering controls; Add is hidden and disabled.
- This holds after clicks, checkbox changes, repeated transfers and drag-and-drop in either direction.
- Selection, counts, numeric order and submitted fields retain their existing behavior. Save Survey is still required to persist changes.

## Update notes

All new `UPDATE-v*.txt` release instructions are placed in **docs/updates/**, never in the project root. Historical update notes supplied by earlier project ZIPs are also included there.

`php artisan cmo:organize-update-notes` moves existing root `UPDATE-v*.txt` files into that directory. Identical root copies are removed only after verifying that the destination contains the same bytes. If different content already exists under the same filename, both versions are preserved using a `-moved-N` suffix. Unrelated files and the fixed README are left untouched. Source symlinks are skipped, and symlink destination directories are rejected.

The command is safe to rerun. It performs no database changes.
