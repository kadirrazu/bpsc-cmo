# bpsc-cmo v0.5.1 — clear question removal and user designation

## Apply

Apply after v0.5.0. Extract the Paste & Replace ZIP into the project root and run:

```bash
php artisan optimize:clear
```

No new migration or dependency changes are required. Compiled frontend assets are included. The fixed `readme.md` is unchanged.

## Removing questions from a survey

Each Selected Questions row now has an explicit **Remove** button next to Up/Down. This works for both previously saved survey questions and questions just added during the current edit.

Click Remove, or untick the question's checkbox, then click **Save Survey** to persist the change. The question returns to the available bank; it is not deleted from Question Bank or other surveys. Remaining selected questions are renumbered automatically. A removed question can be selected again before saving.

When JavaScript is disabled, untick the checkbox and save. Draft surveys can have no selected questions. An active survey must retain at least one active question; switch it to Draft before removing all active questions. Existing responses remain unchanged.

Removal announces the change to assistive technology and moves focus to a remaining selected question, or to bank search when none remain. A bank-search filter does not prevent removal.

## Signed-in user identity

The header's account dropdown trigger displays the user's name in bold on the first line and designation in smaller, regular-weight text on the second line. It is visible on desktop and mobile, with truncation for long text and full text in the title attribute. The expanded dropdown retains name, designation and unit information. Unassigned designations use the existing Not assigned fallback.
