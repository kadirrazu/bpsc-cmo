# bpsc-cmo v0.6.1 — filter alignment, designation and numeric pagination

## Apply

Apply after v0.6.0. Extract the Paste & Replace ZIP into the existing project root and run:

```bash
php artisan optimize:clear
```

No migration or dependency changes are required. Compiled frontend assets are included. The fixed root `readme.md` is unchanged.

## Report filter alignment

The filter row now aligns its columns at the top instead of bottom-aligning against the taller Expert search/help area. Expert, Pool Type and Survey controls share the same 48px height and start position. Additional selected-expert details no longer push neighboring controls downward.

## Expert designation

Expert identity labels now include name, optional designation, pool type and organization. The same label is used for initial/native options and remote selections, so designation remains visible after choosing an expert or returning to a filtered page. Search results continue to show designation among their details. The selected identity summary also retains the complete label. This shared presentation applies to both reports and attendance expert pickers.

## Submissions pagination

Submissions now use a fixed **20 records per page**, including Expert profile history. The previous 10/20/50 selector is removed. Existing valid legacy page-size query parameters are normalized to 20.

Top and bottom pagination include **Previous, numeric page links and Next**, with current-page indicators and first/last-page links plus ellipses for long lists. Empty/single-page lists retain clear counts and disabled navigation states.

Expert browsing and submission pagination remain independent. Numeric links preserve the selected expert and validated filters. CSV exports still include all matching records and are not restricted by the displayed page.
