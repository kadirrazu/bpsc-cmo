# bpsc-cmo v0.6.0 — report Expert search and paginated browsing

## Apply

Apply after v0.5.4. Extract the Paste & Replace ZIP into the existing project root and run:

```bash
php artisan optimize:clear
```

No new migration or dependency installation is required. Updated compiled frontend assets are included. The fixed root `readme.md` is unchanged.

## Searchable Expert filter

The Expert filter now reuses the searchable selection experience from attendance. Search by name, organization, designation or specialization, then choose a result. Results are fetched in pages of 20 instead of loading the entire pool into the report form.

Clear the selection to return to **All experts**. Typing a name without selecting a result does not silently apply an invalid filter. A selected expert outside the first result page remains visible. Historical report searches include inactive and removed experts so their submissions remain accessible. The lookup endpoint requires Administrator/Chairman report permission and does not return contact details.

## One expert at a time

**Question Summary & Rating Averages** now displays one matching expert at a time, ordered by expert name and ID. **Previous Expert / Next Expert** navigation appears above and below the summary, along with the current expert's identity and position in the matching list.

Only experts with submissions matching the selected filters are browsed. Selecting a specific Expert restricts this list to that expert. Removed experts with historical matching responses remain included.

The summary cards, question averages/distributions and Submissions section all relate to the currently displayed expert. Changing experts preserves report filters and resets the submissions page to the beginning for that expert. Existing rating-scale separation and skipped-answer handling remain unchanged.

## Submissions pagination

Submissions display 20 records per page by default. The filter form offers **10 / 20 / 50** records per page. Both top and bottom navigation show record range, total, current page and Previous/Next controls, including disabled states on a single page.

Expert browsing and submission pagination use separate `expert_page` and `submissions_page` parameters. Submission navigation keeps the displayed expert and filters; links scroll to the relevant section. Out-of-range pages fall back to the last available page.

The Expert profile's Evaluation History section uses the same submission navigation and page-size options.

## Exports and permissions

CSV exports continue to include **all records matching the selected filters**, across matching experts, regardless of the expert/submission page currently displayed. The report page states this explicitly. Select a specific Expert filter to export only that expert.

Permissions remain Administrator/Chairman for expert reports, exports and report lookups. Member/Staff are denied direct access. Other module permissions and expert removal restrictions are unchanged.
